# Landing Page LOGIS

## Struktur folder
- `index.html` : halaman utama
- `assets/css/style.css` : desain dan responsivitas
- `assets/js/main.js` : interaksi sederhana
- `assets/img/logo-logis.png` : logo hasil crop dari Company Profile LOGIS
- `assets/img/company-profile-page1.png` : gambar cover sumber logo

## Cara menjalankan
1. Ekstrak folder proyek.
2. Buka `index.html` menggunakan browser.
3. Koneksi internet diperlukan untuk Bootstrap CDN, Google Fonts, Bootstrap Icons, dan foto online di bagian hero serta profil.

## Catatan penyesuaian
- Logo disimpan offline di `assets/img`.
- Foto hero menggunakan gambar online dari Unsplash.
- Data layanan, visi-misi, alamat, email, nomor telepon, dan portofolio diambil dari Company Profile LOGIS 2026.
- Angka portofolio ditampilkan sesuai dokumen: ARS University 1.050 mahasiswa/3 tahun, Universitas Widyagama 970 mahasiswa/3 tahun, dan Universitas Gajayana 170 mahasiswa/2 tahun.
- Belum ditambahkan testimoni karena company profile tidak memuat kutipan testimoni.
- Pastikan kembali detail kontak dan data portofolio sebelum website dipublikasikan.
